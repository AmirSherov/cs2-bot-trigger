# Один файл для запуска

Готовый файл: `E:\projects\gpu-trigger\gpu-trigger-standalone.exe`, приблизительно 30 МБ. Можно скопировать только этот файл на другой компьютер с Windows 10/11 x64 и совместимым GPU/драйвером. Python, CUDA и отдельная установка Visual C++ Redistributable не требуются.

Двойной щелчок запускает LIVE: сначала загружается модель, затем F8 в игровом окне включает реакцию; удержание Mouse4 разрешает нажатия; F10 завершает. Игра и видеодрайвер нужны на целевом компьютере. На других компьютерах и GPU сборка ещё не проверена.

Проверка без кликов:

```powershell
& "E:\projects\gpu-trigger\gpu-trigger-standalone.exe" --dry-run
```

Модель, ONNX Runtime, DirectML и четыре DLL Visual C++ встроены в ресурсы EXE в сжатом виде. При запуске файлы автоматически извлекаются в `%LOCALAPPDATA%\GpuTrigger\<версия>`. Это один файл для скачивания; во время работы используются автоматически распакованные файлы. Установка и права администратора не нужны. На каждом запуске проверяется SHA256 распакованных файлов; исправные файлы повторно не распаковываются. Файлы лицензий также встроены.

Дополнительные аргументы основной программы передаются через оболочку. Например, `--image`, `--preview`, `--confidence`, `--cooldown-ms`. Без аргументов оболочка добавляет `--live`. Если переданы другие параметры, добавь `--live` явно для включения кликов. `--dry-run` и `--live` вместе запрещены.

`--unpack-only` распаковывает и проверяет файлы без запуска распознавания. `--help` выводит доступные параметры. Для повторной сборки: сначала основной `..\build.cmd`, затем `standalone\build.cmd`. `make-payload.ps1` собирает ресурсы из текущей основной сборки и формирует манифест с контрольными суммами. Сам EXE компилируется со статическим runtime `/MT`.

Проверено: сборка `/W4 /WX`, извлечение, повторный запуск, GPU-распознавание исходного скриншота через распакованный EXE, запуск из отдельной папки без соседних DLL, пути с пробелами. Проверка распознавания не генерировала ввод мыши. Оболочка не меняет алгоритм модели и ограничения основной программы.
